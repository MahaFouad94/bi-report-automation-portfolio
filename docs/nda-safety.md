# NDA Safety Checklist

This repository is designed to be safe for public portfolio use.

## Included

- Synthetic KPI data
- Generic business-area names
- Simple Python automation logic
- Public-facing documentation
- Markdown report output

## Excluded

- Client names
- Employer files
- Real dashboard exports
- Real KPI values
- Internal Power BI models
- Confidential business logic
- Screenshots from private dashboards
- Non-public datasets
- Contract, government, transport, or operational details tied to real projects

## Public Portfolio Rule

Only publish material that can be explained without referring to a private client, internal file, restricted dataset, or signed NDA.

When in doubt, rebuild the example using synthetic data and generic labels.
