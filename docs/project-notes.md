# Project Notes

This project is a public demonstration of a reporting pattern, not a reproduction of any workplace system.

## Design Choices

- CSV is used so the data is easy to inspect.
- Markdown is used so the generated report can be viewed directly on GitHub.
- KPI values are small and synthetic to avoid any connection to real operations.
- The code focuses on clarity over production complexity.

## Possible Extensions

- Export the report to Word or PDF.
- Add a Power BI dashboard using the same synthetic CSV.
- Add data-quality checks before report generation.
- Add a small Streamlit interface for filtering KPIs.
- Add automated tests for KPI status logic.
